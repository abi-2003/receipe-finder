
**🍽️ Recipe Finder**

A simple web application that allows users to search for recipes using TheMealDB API.

🚀 Features

✅ Search for recipes by name

✅ View recipe details (ingredients, instructions, and images)

✅ Responsive design

🛠️ Technologies Used
HTML
CSS
JavaScript
TheMealDB API
